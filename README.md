# 🎮 Tutorial Pygame untuk Pemula RPL

Tutorial lengkap belajar **Python + Pygame** dari nol sampai membuat game **Drag & Drop**.  
Dibuat khusus untuk anak-anak yang baru belajar **Rekayasa Perangkat Lunak (RPL)**.

Semua kode sudah diberi **komentar penjelasan** supaya mudah dipahami.

---

## 📋 Daftar Isi

| Folder | Materi |
|--------|--------|
| `01-dasar-dasar` | Instalasi, jendela kosong, warna, dan loop utama |
| `02-menggambar` | Gambar bentuk (persegi, lingkaran, garis, teks) |
| `03-event-dan-input` | Keyboard, mouse, dan event handling |

---

## 🛠️ Persiapan

### 1. Install Python
Pastikan Python 3.8 atau lebih baru sudah terpasang.
Cek dengan perintah:
```bash
python --version
```

### 2. Install Pygame
Buka terminal / command prompt, lalu ketik:
```bash
pip install pygame
```

### 3. Cara Menjalankan
Masuk ke folder materi, lalu jalankan file `.py`:
```bash
cd 01-dasar-dasar
python 01_jendela_kosong.py
```

## 💡 Tips Belajar

1. **Jangan skip** materi. Kerjakan berurutan.
2. **Ubah-ubah** angka dan warna di kode supaya paham.
3. Kalau error, baca pesan error-nya. Biasanya sudah ada petunjuk.
4. Komentar di kode itu temenmu. Baca semuanya!
